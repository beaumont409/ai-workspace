# Blueprint Technology subdomain source snapshots

`unlocks.blueprinttechnology.dev/index.html` and
`redirect.blueprinttechnology.dev/index.html` are the dedicated live webroot
files captured from `/var/www/unlocks` and `/var/www/redirect`. Each matched its
corresponding source file under `/root/server-blueprint/sites/` at capture time.

The sanitized renewal metadata for each certificate is under
`../deployment-config/ssl-renewal/`. Certbot account identifiers are redacted.
Certificate and private-key contents are intentionally excluded. Shared payment
code, databases, customer records, and mixed system backups are not included.
